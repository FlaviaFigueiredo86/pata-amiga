Pata Amiga

Um lar para cada patinha!

O Pata Amiga é um projeto desenvolvido com React que tem como objetivo facilitar a divulgação de animais disponíveis para adoção, aproximando cães e gatos de pessoas que desejam oferecer um novo lar cheio de carinho e cuidado.

Sobre o projeto

A plataforma apresenta uma vitrine de animais disponíveis para adoção, permitindo que os visitantes conheçam algumas informações sobre cada amiguinho e acessem o link para saber mais sobre o processo de adoção.

Funcionalidades

Exibição de animais disponíveis para adoção.

Cards individuais com informações dos animais.

Identificação de nome, espécie, idade e cidade.

Fotografias dos animais.

Links para conhecer mais sobre cada animal.

Layout responsivo, adaptado para diferentes tamanhos de tela.

🛠️ Tecnologias utilizadas

React

JavaScript

HTML5

CSS3

Vite

Organização do projeto

App.jsx: estrutura principal da aplicação.

AnimalCard.jsx: componente responsável pela apresentação de cada animal.

VitrineAnimais.jsx: componente que organiza a vitrine.

animais.js: lista de dados dos animais.

VitrineAnimais.css: estilos dos cards e da vitrine.

App.css: estilos gerais da aplicação.

Como executar o projeto

Clone este repositório.

Abra a pasta do projeto no VS Code.

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npm run dev

Acesse o endereço indicado no terminal, geralmente http://localhost:5173/.

🎯 Objetivo acadêmico

Este projeto tem como finalidade praticar o desenvolvimento de interfaces utilizando React, trabalhando com componentes reutilizáveis, propriedades (props), listas de dados em JavaScript e renderização dinâmica com o método map().
